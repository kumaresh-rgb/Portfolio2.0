# Portfolio is Coming Soon

## Demo

A modern, interactive portfolio showcasing Microsoft Stack technologies with stunning animations.

## Features

- **Big Bang Animation**: Tech stack icons burst from center with particle effects
- **Orbital Motion**: Continuous rotation of technology icons around profile
- **Responsive Design**: Optimized for all screen sizes
- **Modern Tech Stack**: .NET, React, Angular, Azure, SQL Server, Power BI, Kubernetes, Docker, and more

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: CSS3 with custom animations
- **Technologies**: Microsoft Stack (.NET, Azure, SQL Server, Power BI, etc.)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
